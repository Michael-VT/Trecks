## Состав проекта

| Файл | Роль |
|---|---|
| `index.html` / `app.js` | клиент: сайдбар каталога, карта Leaflet (canvas), режимы, статистика, проигрыватель, загрузка файлов с ПК |
| `serve.py` | LAN-сервер + `/api/tracks.json`: индекс `tracks/` и `newtreks/`, итоги из шапки Huawei-экспорта, кэш `.trackscache.json` по mtime |
| `tracks/` | 6 симулированных демо-треков у Эйфелевой башни (2 ходьба GPX, 2 бег TCX, 2 вело GPX; везде время+высота+пульс) |
| `newtreks/` | личные треки пользователя (~166 активностей, Huawei), в git НЕ попадает |
| `.github/workflows/pages.yml` | деплой на GitHub Pages с cache-bust |

## Известные особенности / ограничения

- Пульса в личных треках (newtreks) нет — экспорт Huawei его не пишет;
  «Пульс» активен только на демо/загруженных файлах с HR.
- На Pages каталог недоступен (нет serve.py) — там только демо-треки
  и загрузка файлов с компьютера.
- Средняя скорость в анонсе = device totalTime; статистика считает
  по времени точек — маленькие расхождения возможны.
