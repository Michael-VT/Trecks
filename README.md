# Trecks Visualizer

Визуализация GPS-треков (GPX / TCX / KML) на карте Leaflet: панель выбора
треков с анонсом (длина, время, скорость, набор высоты), раскраска по
скорости/высоте, сводная статистика.

Версия — в файле `VERSION` (видна в заголовке панели и в ответе
`/api/tracks.json`). Релизы помечаются git-тегом `v<версия>`:

```bash
echo "1.0.1" > VERSION && git add VERSION && \
git commit -m "v1.0.1" && git tag v1.0.1 && git push --tags
```

## Запуск

```bash
python3 serve.py
```
[Попробовать](https://michael-vt.github.io/Trecks/)
Откроется на `http://localhost:8000/`. Сервер печатает и LAN-адрес
(например `http://192.168.1.108:8000/`) — откройте его на телефоне
или любом устройстве в той же Wi-Fi сети.

- Другой порт: `python3 serve.py --port 8080`
- Кэш отключён: правки файлов видны по обновлению страницы (F5).
- Первый запуск на macOS может спросить разрешение файрвола — разрешить.

## Треки

Положите `.gpx` / `.tcx` / `.kml` в `tracks/` или `newtreks/` — при
обновлении страницы они появятся в списке. Форматы одной активности с
одинаковым именем объединяются (берётся самый полный: TCX > GPX > KML).

Сервер строит каталог `/api/tracks.json`: итоги (дистанция, время,
набор высоты) читаются из шапки экспорта Huawei, макс. скорость
считается по точкам со сглаживанием. Результаты кэшируются в
`.trackscache.json` — пересчитываются только новые файлы.

`newtreks/` и кэш в git не попадают (см. `.gitignore`).

## Интерфейс

| Элемент | Действие |
|---------|----------|
| строка в списке | выбрать/снять трек (можно несколько) |
| ＋ Файл с компьютера | загрузить .gpx/.tcx/.kml с диска (или перетащить на карту) — попадает в список и выбор |
| демо-треки | 6 симулированных маршрутов у Эйфелевой башни (ходьба/бег/велосипед) в `tracks/`, открываются при запуске без сервера |
| поиск и чипы | фильтр по названию и типу (Бег/Велосипед/Ходьба) |
| Скорость / Высота | режим раскраски (Пульс появляется, если в треках есть пульс) |
| Поправка высоты | сместить высоты так, чтобы минимум = 0 (уровень моря) |
| ползунок | толщина линии 2–32 (точки наведения масштабируются) |
| слои (справа внизу) | Карта / Спутник / Рельеф + подписи поверх спутника |
| ▶ | проигрыватель: идти по маршруту с камерой (×1…×16, ⏮ — в начало) |
| клик по точке трека | панорама Google Maps в этой точке |
| Статистика | сводка по выбранным трекам |
| ✕ / ☰ | скрыть/показать панель (удобно на телефоне) |

Клавиши: `S` скорость, `H` высота, `P` пульс, `T` статистика.
Наведение на точку трека (2 сек) — тултип с данными точки.
